示例

站点的目标很简单：打开快、改起来简单、十年后还能编译。你现在看到的每个页面都是构建时生成的静态 HTML，没有数据库，也没有需要续费的服务。

为什么是静态站

平台的价值在于让你少配置，代价是你不拥有它。文章是本地文件 content/blog/*.md，样式是你自己的 CSS，部署是一个免费的 CDN。

先写够十篇，再回来调视觉。顺序反过来的人，通常一篇都没写完。
npm run dev      # 本地预览
npm run build    # 构建 + 生成搜索索引
